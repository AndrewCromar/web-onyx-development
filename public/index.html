DREWSWEEPER

Drew's version of minesweeper.

About

Drewsweeper is a game we made in about four hours. Inspired by a random conversation, we jumped straight into development. A few hours later, the game was fully playable and uploaded to Itch.io. While it retains the classic Minesweeper mechanics without any gameplay changes, we built it entirely from scratch to learn the ropes and created our own custom textures.

HELL HOTEL

Very scary horror game.

About

Hell Hotel is a small horror game set inside a haunted hotel. Playing as the main character, Rose, you start trapped inside and must explore the hallways to uncover the hotel's secrets and find a way out.
